# Networkwalks-B084k-of-Week1-Wireshark-Project
Cybersecurity Lab setup
Throughout this Wireshark project, I have built core, practical skills in network traffic analysis, security auditing, and packet inspection, which are essential for a Security Operations Center (SOC) analyst.
:Lab 1: Identify the Attacker's IP
In this lab, I monitored live network traffic using Wireshark, filtered TCP connection SYN packets, and successfully identified a port-scanning attack by tracing both the attacker's and the target server's IP addresses. 
Lab 2: Follow TCP Stream 1
Using Wireshark's "Follow TCP Stream" feature, I tracked suspicious TCP conversations, which allowed me to seamlessly read, rebuild, and analyze the messages and data exchanged between the client and server.  
Lab 3: Follow TCP Stream, Part 2
In this lab, I practiced filtering complex, multi-stream traffic, leveraging specific stream indexes and decoding payload data to locate and extract hidden flags and sensitive information buried within the network.
Lab 4: HTTP Plain Text Credentials
During this lab, I analyzed unencrypted web traffic and HTTP protocol communications, pinpointing clear-text usernames and passwords transmitted without encryption via HTTP POST requests.
Lab 5: Catch the Brute Force Attacker
In this lab, I inspected repeated failed login attempts and network requests originating from a single source IP, successfully spotting an automated dictionary/brute-force attack aimed at cracking passwords.
Lab 6: Catch the Call Scammer
Using this lab, I analyzed VoIP traffic captures, utilizing Wireshark's "VoIP Calls" features and SIP/RTP streams to investigate a recorded scammer conversation and review call metadata through the audio player.
